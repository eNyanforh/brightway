# BrightWay

BrightWay is a global digital ecosystem for professional identity, verified organizations, networking, opportunities, education discovery, messaging, and a Liberia-enabled Virtual Campus.

## Architecture

This repository is the brand-new BrightWay MVP codebase. It follows the locked BrightWay Master Architecture.

- `frontend/` — React + Vite + React Router + styled-components
- `backend/` — Node.js + Express + Prisma + PostgreSQL
- API prefix — `/api/v1`

## MVP rule

BrightWay is global. Virtual Campus is currently available only to eligible organizations operating in Liberia.

## Development

Sprint 1 establishes the project foundation, identity, authentication, 2FA, profiles, demographics, education, experience and verification.
