# Virtual Campus temporarily retired — November 19, 2026

BrightWay's Virtual Campus, Grade School and TVET workspaces, student/guardian context switcher, setup flow, and Campus billing are **not active product features** during the current launch phase.

- School and training organizations use the normal Organization workspace and retain their existing programs, admissions, opportunities, posts, and credential reviews.
- Legacy `/campus/:id` and `/organization-workspace/:id/campus` URLs redirect to the institution's normal Organization workspace.
- The API router no longer mounts Campus, Grade School, TVET, my-campus, or Campus billing endpoints. Direct requests therefore cannot create, change, or inspect Campus records through active HTTP APIs.
- The backend authorization catalog no longer offers `organization.campus.*` permissions, including if old permissions remain stored.
- Campus billing's scheduled-worker entry point is a safe no-op; no Campus charges or reminder notices should be generated by it.
- The management Campus billing tool and Campus promotion surfaces are removed.

**Preservation:** All Prisma models and previously deployed database migrations remain. Existing records, including academic registrations, assessments, payments and audit trails, are not deleted. Dormant implementation remains in Git history and portions of the source tree for possible future restoration. This change is a reversible retirement, **not a database purge**.

**Release verification:** Run frontend lint, build, unit tests; backend syntax, unit and integration tests; browser navigation smoke checks; then verify all retired API routes are unavailable in deployed environments. Confirm existing organization, learning, staff, admissions and management workflows remain operational. Stop any separately hosted legacy Campus billing job or worker deployment; the repository worker is no-op only when updated code is deployed.
